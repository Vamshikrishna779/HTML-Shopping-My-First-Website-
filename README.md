# VG's - E-Commerce Website
## Overview
This is a fully functional e-commerce website built using **HTML, CSS, JavaScript, PHP, and XAMPP**. It includes user authentication, product listings, and payment integration using Razorpay.

## Features
- **User Authentication**  
  - Signup and Login functionality  
- **Product Listings**
  - Oneline Shoping Page with all elctronics, clothing, mobiles etc..
  - Grocery page with various items  
- **Payment Integration**  
  - Razorpay for secure online transactions  
- **User Profile Management**  
  - Profile page for managing user details  
- **Customer Support**  
  - Customer care section for queries and support  
- **Responsive UI**  
  - Optimized for various screen sizes  

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP
- **Database:** MySQL (via XAMPP)  
- **Server:** XAMPP (Localhost)  
- **Payment Gateway:** Razorpay  

## Installation & Setup
### Prerequisites:
1. Install **XAMPP** ([Download Here](https://www.apachefriends.org/download.html))
2. Clone this repository:
   ```bash
   git clone https://github.com/your-username/ecommerce-website.git
   ```
3. Move the project folder to the **htdocs** directory in XAMPP.

### Database Setup:
1. Start **Apache** and **MySQL** from the XAMPP control panel.
2. Open `http://localhost/phpmyadmin/` in a browser.
3. Create a new database (e.g., `ecommerce_db`).
4. Import the provided SQL file (`database.sql` if available) into phpMyAdmin.

### Running the Project:
1. Start XAMPP and ensure **Apache** and **MySQL** are running.
2. Open your browser and go to:
   ```
   http://localhost/ecommerce-website/index.php
   ```
3. Signup, login, browse products, and test payment functionality.
